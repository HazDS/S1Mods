## Reporting Issues

Before creating an issue, please:

1. **Check existing issues** to avoid duplicates
2. **Include the mod name** in your issue title (e.g., `[SuperGrow] Bug description`)
3. **Provide your game version** and mod version
4. **Include your MelonLoader log** if reporting a bug (`MelonLoader/Latest.log`)
